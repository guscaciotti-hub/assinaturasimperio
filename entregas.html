Império Global Telecomunicações · instruções de instalação

Como instalar

  1. Localize o seu nome nesta página.
  2. Clique em Copiar a minha assinatura.
  3. Abra o Outlook e siga o caminho correspondente à sua versão (abaixo).
  4. Cole no campo da assinatura com Ctrl + V.
  5. Guarde as alterações.

Outlook na Web ou novo Outlook

Definições (roda dentada) → Correio → Compor e responder → Assinatura de correio eletrónico.

Outlook clássico para Windows

Ficheiro → Opções → Correio → Assinaturas → Nova.

Gmail

Definições (roda dentada) → Ver todas as definições → separador Geral → Assinatura → Criar → colar no editor → Guardar alterações, no fundo da página.

No Gmail: ao colar, o logótipo é carregado automaticamente para os servidores do Google. Aguarde que a imagem fique visível no editor antes de guardar. Confirme ainda, no mesmo ecrã, que a assinatura está seleccionada em PARA NOVOS E-MAILS e em EM RESPOSTA/REENCAMINHAMENTO.
Importante: active a assinatura tanto para mensagens novas como para respostas e reencaminhamentos. Não altere tipos de letra, cores nem dimensões após colar — a assinatura já está normalizada segundo a identidade da empresa.
